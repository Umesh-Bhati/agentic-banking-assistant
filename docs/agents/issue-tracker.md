# Issue tracker

Issues and tickets for this repository are managed locally as Markdown files under the `.scratch/` directory.

- Features and tasks are broken down into numbered markdown files (e.g. `.scratch/<feature-slug>/issues/01-<slug>.md`).
- Agents must use file reading/writing tools (not the GitHub CLI) to interact with the issue tracker.
- External PRs (if any) are not part of this local issue tracking system unless explicitly requested.
