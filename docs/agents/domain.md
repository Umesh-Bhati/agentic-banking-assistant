# Domain docs

This repository uses a **single-context** architecture.

- Domain concepts, glossary terms, and overarching architecture rules belong in root Markdown files (e.g., `Architecture-Spec.md` or `CONTEXT.md`).
- Architectural Decision Records (ADRs) live in `docs/adr/`.
- Agents must consult these files to ensure all terminology and structural choices align with the repository's documented standards.
