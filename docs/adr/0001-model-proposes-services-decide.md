# The model proposes; deterministic services decide

Mastra is limited to language reasoning, read orchestration, and bounded action proposals because model output cannot safely establish banking authority. Customer-scoped backend services, trusted UI confirmation, fresh configured-method authorization, and PostgreSQL transactions own every consequential state transition, accepting the extra multi-request coordination in exchange for complete mediation, replay resistance, and auditable outcomes.

## Consequences

Model prose, tool choice, and generated JSON cannot confirm success or execute a banking operation. Private resource values bypass model context, proposal tools receive temporary aliases, and every new sensitive service must provide a typed proposal event plus a deterministic confirmation, authorization, execution, and audit path.
